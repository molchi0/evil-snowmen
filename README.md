# Evil Snowmen — мод на злых снеговиков (Fabric, Minecraft 26.2)

## Что делает мод
- **Злой снеговик**: форма обычного снеговика, но снег **грязный** (пятна земли, копоть, подтёки), а на голове **злая тыква** с вырезом: брови-«уголки», красные глаза, зубастый рот.
- Он **агрессивный**: видит игрока за 24 блока и стреляет **грязными снежками** раз в секунду.
- Снежок наносит **3 урона** (1,5 сердца) и **замораживает**:
  - иней на экране и урон от обморожения (как в powder snow),
  - **Замедление I на 30 секунд**, как у стрелы зимогора.
  - Кожаная броня защищает от обморожения (как в ванили).
- Спавнятся в заснеженных биомах (равнины, тайга, склоны, ледяные шипы, пики), днём и ночью.
- Выпадает 0–15 снежков и с шансом 15 % вырезанная тыква.
- Сами снеговики не замерзают и друг в друга не стреляют.
- **Добрые (обычные) снеговики дерутся со злыми**: их снежки наносят злым 2 урона (1 сердце), а злые стреляют в ответ (`GOOD_SNOWBALL_DAMAGE` в `EvilSnowman`).

## Сборка через GitHub (без установки Java)
1. Создай на github.com новый репозиторий (например, `evil-snowmen`).
2. Загрузи в него **всё содержимое папки проекта**, включая скрытую папку `.github`
   (проще всего через GitHub Desktop или `git push`; при загрузке через веб-страницу перетащи папки целиком).
3. Открой вкладку **Actions**. Сборка запустится сама после загрузки; если нет, выбери **Build mod → Run workflow**.
4. Когда появится зелёная галочка, открой запуск и внизу в разделе **Artifacts** скачай `evil-snowmen-mod`.
   Внутри будет готовый `.jar`, его кладёшь в `mods` вместе с Fabric API.
5. Если сборка красная, открой шаг **Build** и пришли мне текст ошибки.

## Как собрать локально
1. Нужна **JDK 25** (например, Eclipse Temurin 25).
2. В папке проекта выполни:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `./gradlew build`
3. Готовый мод: `build/libs/evil-snowmen-1.0.0.jar`.
4. Положи его в `mods` вместе с **Fabric API** для 26.2.

Для запуска из IDE (IntelliJ IDEA): открой папку как Gradle-проект и запусти задачу `runClient`.

## Как проверить в игре
```
/summon evil_snowmen:evil_snowman
/give @s evil_snowmen:evil_snowman_spawn_egg
```

## Что где лежит
| Что | Где |
|---|---|
| Поведение снеговика | `src/main/java/net/evilsnowmen/entity/EvilSnowman.java` |
| Снежок: урон, заморозка, замедление | `src/main/java/net/evilsnowmen/entity/EvilSnowball.java` |
| Модель | `src/main/java/net/evilsnowmen/client/EvilSnowmanModel.java` |
| Текстура снеговика и тыквы | `src/main/resources/assets/evil_snowmen/textures/entity/evil_snowman.png` |
| Текстура снежка | `src/main/resources/assets/evil_snowmen/textures/item/dirty_snowball.png` |

Настроить силу можно в константах `EvilSnowball` (`DAMAGE`, `SLOWNESS_TICKS`, `FREEZE_TICKS`) и в `EvilSnowman` (здоровье, частота выстрелов).

## Если не собирается
Minecraft 26.2 очень свежий, а в нём меняются названия классов. Версии в `gradle.properties` (Loom, Fabric API) сверь с https://fabricmc.net/develop/. Если компилятор ругается на какое-то имя, пришли мне текст ошибки, и я поправлю.
